# Contributing to the Mergington High Extra-Curricular Activities Website

Thank you for your interest in improving our school's website!

## Development Setup
1. Clone the repository.
2. Install Python requirements: `pip install -r requirements.txt`.
3. Start the development server: `python src/app.py`.
4. Visit http://localhost:8000.

## Making Changes
1. Create a descriptive feature branch.
2. Make and test your changes locally.
3. Push your branch and open a pull request.
4. Address any review feedback.

## Code Style
- Follow PEP 8 for Python code.
- Use descriptive variable names.
- Add comments to clarify complex logic.

## Need Help or Have Ideas?
- Check existing GitHub issues before opening a new one.
- Attend IT Club office hours on Thursdays in Room 203.
- Email techclub@mergingtonhigh.example.edu for assistance.
